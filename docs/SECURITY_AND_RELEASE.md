# 安全、可信展示与发布门槛

## 1. 威胁—控制矩阵

| 威胁 | 最低控制 | 剩余边界 |
|---|---|---|
| prompt injection要求执行脚本 | JSON数据边界、白名单原语、无exec/eval | 模型仍可能生成语义错误候选 |
| 恶意规则消耗CPU/内存 | 包大小、AST深度/数量、实体/命令/tick配额、独立worker | 公网需更强资源隔离 |
| 无限产物/功率翻倍 | 环境统一配额、原子库存、质量tag和能源账本 | 游戏经济不等于真实物理 |
| 两次请求重复扣料或退款 | 持久化幂等键、同ID异payload拒绝、单writer | 客户端新ID代表新命令 |
| 候选与验证报告替换 | candidate/context/testsuite/verifier hash全部绑定 | 测试覆盖不等于完整证明 |
| 用户盗改他人世界 | 对象级权限、入队和执行时再次验证 | owner仍有本世界管理权 |
| 包文件路径穿越/zip bomb | 展开后路径归一、禁绝对路径/../symlink、文件数与体积上限 | 所有导入视为不可信 |
| 缺包/错误engine版本导致错误复现 | manifest固定摘要、版本匹配、显式拒绝 | 不提供魔法跨版本兼容 |
| 索引器被伪造tx_hash欺骗 | 独立读链验证事件/合约/参数 | 读链服务也需可用性与运维 |
| 前端泄露钱包私钥 | 浏览器钱包本地签名、服务不接触seed | 恶意浏览器扩展属于额外风险 |
| 链重组重复触发游戏奖品 | v1无链上奖品兑付；状态系统分离 | 不存在跨系统原子性保证 |
| 开源规则被复制 | 不宣称NFT防复制；许可与署名明确 | 登记不能自动判原创 |
| 公开资料泄露用户聊天 | 最小化日志、公开导出脱敏、提示不默认上传 | 公网内容不可当可撤回私密存储 |

## 2. 资源上限初始值

公开服务前须按实测修订；以下为设计初始值，不是性能测量：候选64KiB；蓝图16节点；世界128实体；表达式深度8、总节点64；一个world待执行命令队列最多1000条；每会话写入最多10条/秒，超限返回429；每用户并发编译最多1个；每候选最多3次模型请求；验证最多10场景×120tick；导入包最多100文件、解压总量10MiB、单文件2MiB。普通小蓝图JSON限制仍为64KiB，不因ZIP包限制而放宽。

limits属于policy的一部分并进入policy_hash。不能让候选自身提高这些上限。超限拒绝也不能绕过幂等日志或漏记已有命令结果。

## 3. M0–M2离线门槛

安装依赖与运行游戏分别说明。测试在预备好依赖的环境中阻断网络；核心不能import HTTP/模型/链SDK。不读取用户真实账户或浏览器cookie。不隐藏模拟异常。验证worker可以用固定受控命令启动，但不能把候选内容当命令执行。

## 4. 公开服务前门槛

确认会话/Origin/CSRF、密码或登录供应商策略、限流、对象级授权、输入长度、上传隔离、TLS、敏感日志清理和持久化备份。所有默认密码与开发session关闭。编译worker和运行world actor有进程资源边界。根据部署系统配置内存/CPU/文件/进程限制；不要声称Windows本地开发模式与公网隔离能力相同。

数据库迁移和恢复演练通过；存在版本化engine/catalog/policy可供回放；有明确暂停受影响世界的操作；用户导出可取得完整数据而非只有不可用CID。

## 5. AI公开演示门槛

至少展示一次非fixture自由输入、一次验证拒绝、一次断AI持续运行、一次跨进程导入后执行；公布版本与支持范围。展示失败时给准确错误，不用AI生成旁白替代实际执行。不宣传“任意机制”“完全自主物理”“全球唯一”。

M0–M2只够演示确定性规则引擎；只有M4完成并实际测试，才能称AI编译闭环。用户未开启远程服务时只能显示离线演示。

## 6. 链公开演示门槛

首先本地合约测试；之后若经批准测试网演示，明确标注testnet、登记声明和验证边界。没有私钥进后端，没有付款/收益模块，没有任何真实资金托管。登记与完整内容可以独立核查，但不宣称原创产权裁定、游戏去中心化治理或无信任模拟正确性。
