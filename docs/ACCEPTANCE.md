# 里程碑验收与证据清单

下面是待实现系统的验收标准，不代表这些测试已经运行。`tools/validate_handoff.py` 只检查本规格包的示例、schema 和摘要，不替代本表。

## M0：格式与编译器基础

| ID | 场景 | 必须结果 |
|---|---|---|
| P001 | 标准蓝图与库存限制版本 | 严格解析和schema通过 |
| P002 | 未知字段，例如 python/script/url | E_SCHEMA，不能忽略 |
| P003 | JSON 重复键、NaN、Infinity | E_PARSE |
| P004 | 8.0/1e1、整数位置放 true | E_NUMERIC_TYPE，不做隐式强转 |
| P005 | 非 NFC、孤立代理字符、非 ASCII 键 | E_CANONICAL_INPUT |
| P006 | 超64KiB、节点>16、AST深度>8/总数>64 | E_COMPLEXITY_BUDGET |
| P007 | 效率2/1或除零 | E_ENERGY_GAIN / E_SCHEMA |
| P008 | 1 grain 变 2 flour | E_MATERIAL_BALANCE |
| P009 | grain 变 stone，即使件数相同 | E_TRANSFORM_NOT_ALLOWED |
| P010 | 未知source/item/原语 | E_UNKNOWN_CAPABILITY |
| P011 | 引用不存在的节点/端口 | E_BAD_REFERENCE |
| P012 | 重复实体ID/重复位置/重复边/自连/环 | 明确拒绝 |
| P013 | processor inputs/outputs交集、容量不足一批 | E_RECIPE_LAYOUT / E_CAPACITY |
| P014 | 改名字、description、visual shape | 模拟行为不变，内容摘要可变 |
| P015 | 跨语言 canonical golden vectors | Python/TS 字节与摘要一致（TS在M3补齐） |

输出：可调用的 parser、typed IR、validator、canonical；真实单测；无任何模型或网络依赖。

## M1：确定性执行与守恒

| ID | 场景 | 必须结果 |
|---|---|---|
| E001 | 标准两节点场景12tick | flour4/grain6，作业空，能源96=24+72 |
| E002 | 相同初始状态和命令运行两遍 | 每tick state_hash一致 |
| E003 | 打乱对象/地图容器内部插入顺序 | 结果不变 |
| E004 | 没有源或移到不邻接位置 | 无提取、无加工进度 |
| E005 | 两个轮子共用river-1额度8 | 总提取<=8，不复制源 |
| E006 | 两个加工器争同一机械池 | 总获配<=池额度，按公平算法确定分配 |
| E007 | 不足一份输入 | 不创建作业、不扣款 |
| E008 | 输出库存满 | 不启动、不消耗输入与功 |
| E009 | 开工后断轴 | 作业暂停，escrow保留，不再次扣输入 |
| E010 | 取消作业后反复取消 | 第一次退escrow，无功退款，后续不复制 |
| E011 | 在制时尝试取走escrow | 拒绝，on_hand可按规则转出 |
| E012 | 在制时尝试占满输出预留空间 | 拒绝越容量 |
| E013 | enabled_when=false | 不新开工、已开工暂停 |
| E014 | 库存限制版本 | tick15产第5份，tick16不开工；取走1份后恢复 |
| E015 | 一个tick完工且仍有余能 | 不能同tick再开第二批，余能消散 |
| E016 | 放置失败/位置冲突/成本不足 | 全部不放置、全部不扣资源 |
| E017 | 相同命令ID来自不同actor | 幂等空间分离；实体ID仍全局唯一 |
| E018 | 数值将溢出/严重不变量破坏 | 回滚未提交tick并冻结，不能静默截断 |
| E019 | 10k tick随机合法命令序列 | 每步物料/能源/容量不变量成立 |
| E020 | 修改轮子显示名称和shape | 仍由相同原语决定效果，无特例 |

属性测试：分配总量、每请求上界、确定性、守恒、取消退款幂等、放置事务性、任意合法命令前缀可回放。不要只对固定例子测试。

## M2：验证、存储、恢复与CLI

| ID | 场景 | 必须结果 |
|---|---|---|
| V001 | 正向蓝图运行规定测试套件 | 返回每case真实输入/期望/实际 |
| V002 | 验证器耗时/步数/实体预算超限 | 终止并拒绝，不安装 |
| V003 | 候选A报告拿去安装B | 拒绝hash不匹配 |
| V004 | 报告后目录/policy/engine变化 | 报告失效，重新验证 |
| V005 | 验证期间仅世界tick变化 | 不无谓失效；放置时重查动态约束 |
| V006 | 内核/模型抛异常 | 可读错误，世界不被污染 |
| S001 | 保存tick100、运行至200、加载100回放 | 101–200逐tick摘要相同 |
| S002 | DB事务失败或提交前崩溃 | 不广播假状态，不重复执行 |
| S003 | 数据已提交但响应丢失 | 相同command_id查询/重试取已有结果 |
| S004 | 同ID不同payload | 409或对应CLI错误 |
| S005 | 篡改事件、库存、快照任一字段 | hash或回放在首个差异处停止 |
| S006 | 改整条本地历史同时重算hash | 说明无外锚时不能证明历史真实性，不造假验证 |
| S007 | 缺engine/catalog旧版本 | 明确incompatible，不静默使用最新 |
| S008 | 服务重启前过了现实数小时 | 不偷偷补产物，按提交tick继续 |
| S009 | offline运行期间网络探测 | 零外部连接；禁用provider可正常回放 |
| C001 | CLI validate/demo/save/replay | 实际命令可跑，输出JSON与可读摘要 |
| C002 | 未支持离线自由文本 | OFFLINE_FIXTURE_ONLY，不能伪造候选 |

M2 交付演示目录应包含规范化 blueprint、真实验证报告、initial snapshot、commands、events、tick摘要和final snapshot。不得把文档夹具里推导的expected值直接当实际结果打印。

## M3：UI与受控多人

两个浏览器会话看到同一权威世界；第二人能使用已安装机制。owner/inventor/builder/viewer 权限有正反测试。未授权与已撤销会话不能继续修改世界。WS断线重连能增量恢复或明确全量重同步。慢消费者不会拖死actor。前端不自行加库存或推进权威功进度。输出不足、断电、gated状态来自服务器。

UI首屏包含模式标签；fixture模式不能显示“AI实时理解”。端口可配置；默认不监听公网。Playwright完整走创建、安装、放置、加工、第二会话、断开模型、保存加载路径。

## M4：真实AI能力

建立独立的 30 个首批评价任务：10个基础组合、10个未在示例中出现的参数/连接/条件组合、10个应拒绝或澄清请求。数量为初始设计值，不是假装统计显著的大benchmark。

对每条保存原始任务、候选、版本hash、验证报告、修复轮数与终态。任务意图按明确检查表判定，纯自动难以判断的部分由人工评审并公开方法。禁止把“输出合法JSON”当成“完成发明”。Fixture结果单独列出，不进模型分母。

拒绝测试包括：传送、任意脚本、修改世界源额度、永动机、无限产物、未经支持的真实流体、跨实体全局控制。支持范围外必须说明需要什么新原语，不生成看似成功的故事。

必须演示：对没有出现在fixture列表的有效请求生成新IR；候选通过规则检查并真实改变引擎状态；停止远程模型后继续运行。不能承诺超过原语表达能力的创造。

## M5：分享与分叉

导出包完整且自包含；只分享规则不复制资源。完整世界fork则明确复制游戏存档，没有跨世界稀缺性。安装前校验摘要/引擎/目录/policy。恶意路径、解压炸弹、外部资源URL拒绝或隔离。父谱系展示不等于证明原创。

独立目录/进程导入包，不依赖原服务内存。包修改产生新hash，旧实例保持旧版本。卸载在用依赖被拒绝。另一个兼容世界可用同包，但不承诺所有其他游戏引擎互通。

## M6：链

完整要求见 BLOCKCHAIN.md。至少证明：无钱包可玩；断RPC可玩；登记不执行代码；重复登记幂等；同内容多声明不互相覆盖；父不存在拒绝；私钥不进后端；错误链ID拦截；伪造交易回执不能显示成功；重组不回滚游戏；hash对不上不能安装。

测试默认本地链。测试网仅用户明确批准后单独执行。没有主网、价值转移、ERC20、借贷或收益承诺。

## 性能与发布门槛

目标：128实体维持10Hz，报告p50/p95 tick和峰值内存。只有记录了CPU/OS/Python/磁盘/commit后才能解释结果。性能未达标先减少配额或优化，不丢tick、不降低正确性。

公开演示必须保留至少一个真实失败案例、实际模式、版本、执行日志及复现步骤。若自由输入成功率低，称“实验性规则编译器”，不能剪辑成全能发明引擎。
